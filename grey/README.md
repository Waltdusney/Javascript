# Grey

Pre-launch website and Instagram plan for Grey, a menswear label of heavyweight basics in four greys.

- `index.html`: the website (pre-launch waitlist page), built with taste-skill. Open it in a browser.
- `instagram-plan.html`: Instagram setup, profile picture ideas, first nine posts, creator plan and 19 creators.
- `.agents/product-marketing.md`: the brand's marketing brief, read by the marketing skills.

Before launch:
- The waitlist form has no destination yet (`action` is a `mailto:` on `grey.example`). Connect it to Klaviyo, Mailchimp or Shopify.
- The one photograph (`assets/img/photo-f3037784-500.webp`, a fabric close-up) is a licensed stand-in by teslar, CC BY-SA 3.0, via Wikimedia Commons. Replace it with Grey's own sample photos.
- Product names, colours and copy are proposals; prices are not set.

`assets/` holds the taste-skill kit files the page uses (MIT, see `assets/LICENSE-taste-skill`).
